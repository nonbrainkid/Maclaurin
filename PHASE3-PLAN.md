## Этапы

### 3.1 Независимый аудит фазы 2 — ✅ ВЫПОЛНЕНО

**Результат: Critical / High / Medium / Low — ноль.** Только Info-записи
с подтверждением арифметики. Критерий «ноль находок Medium и выше» выполнен
с запасом.

Что проверялось и что подтвердилось:

| Фокус | Итог |
|---|---|
| Арифметика веса `weight = staked * multiplier / 1e18` | Корректна |
| Переполнение `weight * delta` при максимальных значениях | Максимальный вес **7.388e27**; запас до потолка uint256 — **×1.61e20** |
| `ACC_PRECISION` после смены делителя на `totalWeight` | Гипотеза агента подтверждена: инкремент на эпохе 26 при максимальном весе — **270** против **735** в фазе 1, то есть нижняя граница ужалась ровно втрое. Хвост ряда не обнуляется, `1e30` менять не нужно |
| `poke`: порядок `_accrue` → `_settle` → пересчёт веса | Соблюдён |
| Сжигание награды: попадает ли она в `unallocated` ровно один раз | Да, двойного счёта нет |
| `totalWeight == Σ weight(user)` при всех переходах | Держится |
| Ветки удаления и частичного уменьшения позиции | Корректны |

Числа занесены в `LAUNCH-PLAN.md` (этап 1) и `PHASE2-SPEC.md` §2.
